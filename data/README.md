# Data

The academic report identifies the following source institutions:

- Bank Negara Malaysia — MYR/USD exchange-rate data
- Department of Statistics Malaysia — export growth, Industrial Production Index and Consumer Price Index
- International Monetary Fund — Real Effective Exchange Rate
- CPB Netherlands Bureau for Economic Policy Analysis — World Industrial Production Index

## Folder convention

- `raw/` — source files in their original publishable form
- `processed/` — cleaned/merged datasets used by the model

## Before publishing data

Check the redistribution terms for each source. If a dataset should not be republished, leave it out of this repository and document the download source and preparation steps instead. Do not upload credentials, personal information or unrelated university records.
