# Code

Place the cleaned Python source files used for the econometric analysis in this folder.

Recommended naming convention:

```text
01_data_preparation.py
02_volatility_modelling.py
03_ardl_ecm_analysis.py
04_diagnostics_robustness.py
05_granger_causality.py
```

Before publishing, remove local absolute paths, credentials, student IDs, temporary debugging code and duplicate scripts. Add short comments explaining the purpose of each analytical stage.
