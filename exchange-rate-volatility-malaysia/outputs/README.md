# Outputs

Store only the outputs that help a reviewer understand the analysis.

Suggested folders:

- `figures/` — volatility plots, time-series charts, CUSUM/CUSUMSQ figures and other key visuals
- `tables/` — cleaned model-result and descriptive-statistics tables
- `model-results/` — text/CSV exports of model summaries and diagnostics

Avoid uploading large numbers of duplicate screenshots or temporary console outputs.
